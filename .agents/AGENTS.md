# Project Rules

## Documentation
- Always update the app's corresponding Markdown documentation file (e.g., `DAILY_STOIC.md`, `WANDERLIST.md`, etc.) in the repository root after making any feature additions, modifications, or milestones that need to be recorded.

- NEVER have a transaction take more than 2 rows of screen estate on mobile. Do not break text lines further in the mobile transaction list (preserve existing white-space constraints).
